# Section 1: 12-Month Operating Plan

Month-by-month sequencing. Every task maps to a person or role. **Bold items are critical-path milestones** — miss these and everything downstream shifts.

## Month 1 — Foundation

### Team
- Founder (you): full-time, CEO
- **Hire #1: Technical co-founder / CTO.** Must have shipped generative media at scale. This person builds the orchestrator and generation pipeline. Equity co-founder.
- **Hire #2: Head of Production / EP.** Real credits. Has shipped content to audiences. Equity or near-equity.
- Advisor: SAG signatory entertainment lawyer (outside counsel, not full-time yet)

### Operations
- Incorporate the studio as a Delaware C-corp (standard for VC)
- Incorporate the Community Cinema Foundation as a separate 501(c)(3) (file IRS Form 1023 — takes 3-6 months, **start now**)
- **Secure SAG-AFTRA Theatrical Standard Signatory agreement**
- Set up the monorepo and project directory structure
- Begin land planning on the 500 acres: survey, zoning review, environmental assessment. Identify first 2-3 soundstage locations on the property.
- **Apply to Anthology Fund this month.** Rolling applications, 2-week response time. You want to be in-process before you need the money.

### Creative
- Begin development on Project 1 (the animated short — see [First 5 Projects](./03-first-five-projects.md))
- Begin development on Project 2 (the documentary series)

**Budget:** personal savings or angel checks, $50K-$100K operating runway

## Month 2 — Orchestrator + First Scripts

### Tech
- CTO builds orchestrator v0.1: Claude Code runtime, project bible ingestion, agent routing, cost logging
- Set up vector DB for asset search
- Evaluate and select generative video models: sign API agreements with 2-3 providers
- Stand up the rights management data model (performer consent, asset lineage, training provenance)

### Creative
- **Script lock on Project 1** (animated short, 10-12 minutes)
- Treatment complete on Project 2 (documentary)
- Begin writing Project 3 (live-action short)
- Commission character design for Project 1 (hire a character artist, this feeds LoRA training)

### Business
- First Anthology Fund meeting (if application advances)
- Identify and begin warm outreach to 5 angel investors
- Begin conversations with 3 churches and 2 schools in your region for theater pilot

**Budget:** still pre-raise, $50K-$100K burn

## Month 3 — Generation Pipeline + Angel Round

### Tech
- CTO builds generation pipeline v0.1: model router, shot generation, asset tagging, dedup
- Train first character LoRAs from Project 1 character designs
- Orchestrator v0.2: pre-production agents (breakdown, shot list, storyboard generation)
- **First end-to-end test: generate a 30-second animated scene from script through pipeline**

### Creative
- Storyboards complete on Project 1
- Begin generating Project 1 shots — this is the pipeline proof point
- Script draft on Project 3 (live-action short)
- Lock documentary subjects/interviewees for Project 2

### Business
- **Close angel round: $250K-$500K** from entertainment and tech angels
- Finalize theater pilot agreements with first 3 locations (2 churches, 1 school)
- Order portable cinema equipment for pilot venues (~$90K for 3 kits)

> **Milestone:** a working 30-second animated clip produced end-to-end by your pipeline. This is the demo reel for every subsequent conversation.

## Month 4 — First Content Ships

### Tech
- Audio pipeline v0.1: score sketching, foley, dialogue processing
- Post pipeline v0.1: assembly agent, color first-pass
- Distribution pipeline v0.1: trailer cutting, metadata generation, social asset creation

### Creative
- **Complete Project 1 rough cut** (animated short, 10-12 minutes)
- Human editor + director review and refine to picture lock
- Sound mix and color on Project 1
- Begin shooting documentary interviews for Project 2 (minimal crew, high AI assist)
- Script lock on Project 3

### Business
- Theater pilot venues receive equipment, begin setup and testing
- Hire venue techs for pilot locations (part-time local)
- Build subscription app MVP (Stripe billing, seat reservation, basic streaming)

> **Milestone:** Project 1 in picture lock. You now have a finished piece of content.

## Month 5 — Launch + Seed Fundraise Begins

### Tech
- Multi-format expansion pipeline v0.1: comic generation, short-form cutting
- Generate comic adaptation of Project 1 (3-5 pages proving the multi-format thesis)
- Generate 10+ short-form social clips from Project 1

### Creative
- **Release Project 1** on YouTube, social, and the subscription platform
- Release comic version simultaneously
- Social distribution blitz: 30+ platform-specific assets
- Begin Project 2 post-production (documentary)
- Pre-production on Project 3 (live-action): casting, location scouting on the 500 acres

### Business
- **Theater pilot launch: first public screenings at 3 locations**
- Track subscriber signups, attendance, revenue share payouts
- **Begin seed fundraise:** armed with Project 1, theater pilot data, and pipeline metrics
- Target: Anthology Fund (if not already closed), a16z, Greycroft, Connect Ventures
- Pitch deck ready (see [Pitch Deck](./04-pitch-deck.md))

> **Milestone:** content live, theaters screening, fundraise launched.

## Month 6 — Seed Close + Production

### Creative

- Shoot live-action days for Project 3 (2-3 days on your land, minimal crew)
- Begin generative production on Project 3 (backgrounds, environments, VFX)
- Begin development on Projects 4 and 5

### Business
- **Close seed round: $2M-$5M**
- Expand theater pilot to 8-10 locations (add 5 churches, 2 schools)
- Hire: 2 more engineers (generation pipeline + platform), 1 marketing/distribution lead
